# ATM location value

Code for the case "Which of 75 ATM locations are worth their cost".

- `build_population.py`: residents near each ATM location, from 2020 Census tracts.
- `model.py`: 5-year NPV of each location, the break-even volume, the access limit and the scenarios.

Both scripts use only the Python standard library. The data files are not in the repository.
