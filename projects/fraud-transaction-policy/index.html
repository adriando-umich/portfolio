SituationWhat the reader knowsAn online merchant accepts card payments. A set of fixed rules approves, reviews or declines each transaction.
ComplicationWhat changed, and what it costFraud loss goes up. Stricter rules decline more good customers, and each false decline costs margin and goodwill. The analyst team can examine only 120 alerts each day, and fixed rules lose value as fraud patterns change.
QuestionThe decisionQ: Which policy gives the lowest total cost of fraud loss, false declines and reviews, with the same review capacity?
